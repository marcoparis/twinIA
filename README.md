notes: |
  A personal and professional AI chatbot developed in Python using Gradio.

  The chatbot is designed to provide information about my professional background,
  work experience, and other personal information.

  The application integrates several tools that dynamically retrieve and provide
  relevant information during conversations. It also includes a notification system
  based on ntfy.sh.

  Notifications: whenever an email address or other contact information is requested
  or mentioned during a conversation, the system can trigger a dedicated notification.

  This allows the chatbot not only to answer questions about my professional and
  personal background, but also to monitor relevant interactions and notify me
  when contact information is involved.
